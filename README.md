# desert-ant-swift

The Desert Ant Labs brand kit for SwiftUI: the bare minimum to put our brand in an app. One product, no dependencies.

```swift
.package(url: "https://github.com/Desert-Ant-Labs/desert-ant-swift", from: "2.0.0")
```

```swift
import DesertAntUI

DA.Mark()                          // the mark on its plate; .inverted and .isolated exist
DA.MarkLoader()                    // the drop loader; honors Reduce Motion
DA.Attribution(prefix: "Runs on")  // the credit lockup for your about screen
Text("Ready").foregroundStyle(DA.Color.textPrimary)
```

The mark and the loader take their color from the environment foreground and size to any frame. The colors resolve light and dark on their own.

`DesignTokens.swift` is generated by the token build in [Desert-Ant-Labs/brand](https://github.com/Desert-Ant-Labs/brand) and copied here; the mark geometry and the loader keyframes are hand ports of that repo's `mark.js` and `loader.css`, pinned by the tests. The rest of the brand lives at [brand.desertant.com](https://brand.desertant.com).
