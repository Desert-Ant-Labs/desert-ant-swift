# Agents

- This is the public Swift brand kit, kept minimal on purpose: the mark, the drop loader, the semantic colors, the attribution lockup. One product, no dependencies. Nothing else comes in; components, fonts, spacing, and model downloading stay out (the old `ModelStore` lives on the 0.x tags).
- `Sources/DesertAntUI/DesignTokens.swift` is generated by the brand repo's token build (`packages/tokens`). Never edit it here; copy the fresh build over and commit.
- The mark geometry (`Mark.swift`) and the loader keyframes (`MarkLoader.swift`) are hand ports of `packages/web/js/mark.js` and `css/components/loader.css` in the brand repo. A change on either side needs the other; the tests pin the values.
- `swift build && swift test` before any PR. Branches: `feature/…`, `improvement/…`, `bug/…`.
- The code is MIT; the name and the mark are trademarks. Do not add brand assets the kit scope excludes (fonts, hand-drawn marks, OG cards).
